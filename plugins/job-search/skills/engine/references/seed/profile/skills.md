# Skill names

One agreed name for each skill that adverts ask for, so the same skill worded
differently in different adverts is counted as one. The coordinator adds a
row when a new skill first appears. To merge two names, keep one row and move
the other name into "Also written as".

"Can be built in" says how long it would take someone starting from nothing
to have something real to show: days, weeks, months, years, or "not by a
project" for things like a right to work. Leave it empty until it matters.
