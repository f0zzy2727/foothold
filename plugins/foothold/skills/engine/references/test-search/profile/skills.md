# Skill names

One agreed name for each skill that adverts ask for, so the same skill worded
differently in different adverts is counted as one. The coordinator adds a
row when a new skill first appears. To merge two names, keep one row and move
the other name into "Also written as".

| Skill | Also written as | Can be built in |
|---|---|---|
| Live event experience | live events, stage crew, load-in | months |
| Excel | spreadsheets, rotas | days |
| QLab | cue software, show control software | days |
| Stage plots | stage plot, input lists | days |
| Lighting basics | lighting rigging | weeks |
| Customer service | dealing with the public, front of house | weeks |
| Driving licence | full driving licence | months |
