# Close the gap

Tailoring a CV presents the past. This skill helps the candidate add to it.
It finds the one missing skill that would open the most doors, across every
advert analysed so far, and turns it into one small real project.

1. Load the `engine` skill from this plugin and read it in full.
2. Open the workspace. If there is no saved search, say so and offer
   start-my-search.
3. Follow "Building evidence" in the engine's modes.

Points specific to this skill:

- Lead with the numbers, in plain words: "QLab comes up in 10 of your 12
  adverts. In 3 of them it is the only essential you are missing." Take every
  number from `pipeline leverage`. Never estimate.
- Say one thing the candidate already has that adverts keep asking for. It
  is true, and it matters to someone getting a run of hard verdicts.
- With only a few adverts analysed, say it is too early to be sure. Do not
  build a plan on three adverts.
- A gap that no short project can close (a licence, a degree, a right to
  work) is named honestly, with what would close it. Do not invent a project
  for it. Move to the next gap.
- The candidate chooses the project and the date, or chooses none. "Not now"
  is an answer: set the ideas aside and do not raise it again for a while.
- One project at a time.
- When it is done, the evidence says only what was done, at the size it was
  done. Then say which verdicts moved and which did not. Do not promise that
  a project will get an interview.
- Opus is the better model for proposing projects. Sonnet is enough for
  recording that one is finished.
